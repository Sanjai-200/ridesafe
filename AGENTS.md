# Agent Guidelines & Operational Rules



This file is automatically loaded by AI coding assistants (OpenAI Codex CLI, Antigravity, etc.).

## Absolute Rules
1. **Branch Rule**: You MUST work exclusively on the `test` branch. Do NOT commit or push to `main` directly.
2. **Merge Rule**: Do NOT merge `test` into `main` unless the human user explicitly gives permission in chat.
3. **Commit Naming Rule**: Every commit MUST be explicitly and accurately named based on the user's specific question, prompt, and exact requested instructions. Never use generic or vague messages. Format: `<type>(<scope>): <clear description reflecting user question and specific changes>`.
4. **Design Rule**: Follow the high-contrast luxury dark theme (`#08080A`, `#141417`, `#FFD60A`) and `'Plus Jakarta Sans'` typography across all views.
5. **Full Workflow Reference**: Read [DEVELOPMENT_WORKFLOW.md](./DEVELOPMENT_WORKFLOW.md) for full architecture, environment details, and deployment URLs.
